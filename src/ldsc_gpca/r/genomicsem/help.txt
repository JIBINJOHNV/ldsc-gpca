usage: ldsc-gpca genomicsem gpca --input MANIFEST.csv --ldsc_results genomicsem_LDSC.RData --outdir DIRECTORY [options]

GPCA/GWAMA from GenomicSEM LDSCoutput RData. Strict QC is the default. Warnings, removals and
errors are saved in GenomicSEM_QC_Events.csv.

options:
  -h, --help                    show this help message and exit

Required inputs:
  --input MANIFEST.csv          Comma-separated manifest; required header traitname. Required;
                                no default.

  --ldsc_results genomicsem_LDSC.RData
                                GenomicSEM LDSCoutput RData; required objects below. Required;
                                no default.

  --outdir DIRECTORY            Output directory; use a fresh directory. Required; no default.

GWAMA inputs (not required with --validate_only):
  --gpca_input_folder DIRECTORY
                                Tab-separated GWAMA input files. Default: unset; package CLI
                                prepares from VCF unless --validate_only.

  --source_path GWAMA.R         Optional custom modified GWAMA R source. Default: bundled
                                N_weighted_GWAMA.function.1_2_6.R.

  --splitby_chr CHOICE          Input naming mode. Default: split (chromosomes 1-22). [Choices:
                                split, nosplit.]

Trait and failed-result handling:
  --allow_missing_traits        Remove absent manifest traits with reasons. Default: off; stop
                                if absent.

  --failed_ldsc_action CHOICE   Stop on invalid trait/pair estimates or remove traits with an
                                audit; never impute. [Default: error.] [Choices: error,
                                drop_traits.]

PCA settings:
  --pca_matrix CHOICE           correlation uses S_Stand; covariance uses GenomicSEM S, on its
                                original scales. [Default: correlation.] [Choices: correlation,
                                covariance.]

  --pc1_orientation CHOICE      tutorial flips ALL PC1 loadings if median<0; as_computed keeps
                                the eigenvector sign. [Default: tutorial.] [Choices: tutorial,
                                as_computed.]

Diagnostic warning/error controls:
  --h2_z_warn_threshold FLOAT   Warn for retained h2/SE below this value; never removes traits.
                                Default: 2; 0 disables.

  --rg_out_of_range_action CHOICE
                                Warn or stop for finite off-diagonal abs(rg)>1; never clamp.
                                [Default: warn.] [Choices: warn, error.]

  --negative_eigen_action CHOICE
                                Warn or stop for substantive negative PCA eigenvalues; no matrix
                                repair. [Default: warn.] [Choices: warn, error.]

  --matrix_eigen_tolerance FLOAT
                                Relative negative-eigenvalue threshold. Default: 1e-8.

Execution and performance:
  --n_cores INTEGER             Chromosome workers. Default: 0 = auto; Windows runs
                                sequentially. Failed jobs retry once, one at a time; failure
                                after 2 attempts stops analysis.

  --validate_only               Write QC and PCA diagnostics without running GWAMA. Default:
                                off.

INPUT FILE CONTRACT
  --input: comma-separated CSV with unique, non-empty traitname header.
    Manifest row order defines matrix, loading and GWAMA input order.
    Package auto-preparation also requires vcf_files if the input folder is omitted.
  --ldsc_results: binary RData containing LDSCoutput, with S,V,I,S_Stand,V_Stand.
    Use genomicsem_LDSC.RData from genomicsem ldsc, generated with stand=TRUE.
    This is NOT a delimited table; the first-pass _raw.RData is not GPCA input.
  --gpca_input_folder: tab-separated TSV files; required columns (extra/reordered columns allowed):
    SNPID,CHR,BP,EA,OA,EAF,N,Z,P (A1/A2/p aliases accepted for EA/OA/P).
    Split: {traitname}_chr{CHR}_GenomicPCA_inputs.tsv (chromosomes 1-22).
    Whole genome: {traitname}_GenomicPCA_inputs.tsv.
  --source_path: optional custom modified GWAMA R source; default is bundled v1.2.6.

AVAILABILITY
  genomicsem ldsc runs GenomicSEM munge/LDSC or accepts existing munged files.
  Both PCA matrix choices write all-PC variance and PC1 protein contributions.
  GWAMA uses PC1 only. GenomicSEM covariance uses S on its supplied scales.
