usage: ldsc-gpca genomicsem gpca [-h] --input MANIFEST.csv --ldsc_path
                                 LDSC.RData --outdir DIRECTORY
                                 [--gpca_input_folder DIRECTORY]
                                 [--source_path GWAMA.R]
                                 [--splitby_chr {split,nosplit}]
                                 [--cores CORES] [--validate_only]
                                 [--allow_missing_traits]
                                 [--failed_ldsc_action {error,drop_traits}]
                                 [--h2_z_warn_threshold H2_Z_WARN_THRESHOLD]
                                 [--rg_out_of_range_action {warn,error}]
                                 [--pca_matrix {correlation,covariance}]
                                 [--pc1_orientation {tutorial,as_computed}]
                                 [--negative_eigen_action {warn,error}]
                                 [--matrix_eigen_tolerance MATRIX_EIGEN_TOLERANCE]

GPCA/GWAMA from GenomicSEM LDSCoutput RData. Strict QC is the default. Warnings, removals and errors are saved in GenomicSEM_QC_Events.csv.

optional arguments:
  -h, --help            show this help message and exit
  --input MANIFEST.csv  Comma-separated manifest; required header traitname.
                        Required; no default.
  --ldsc_path LDSC.RData
                        Native LDSCoutput RData; required objects below.
                        Required; no default.
  --outdir DIRECTORY    Output directory; use a fresh directory. Required; no
                        default.
  --gpca_input_folder DIRECTORY
                        Tab-separated GWAMA input files. Default: unset;
                        package CLI prepares from VCF unless --validate_only.
  --source_path GWAMA.R
                        Optional custom modified GWAMA R source. Default:
                        bundled N_weighted_GWAMA.function.1_2_6.R.
  --splitby_chr {split,nosplit}
                        Input naming mode. Default: split (chromosomes 1-22).
  --cores CORES         Chromosome workers. Default: 0 = auto; Windows runs
                        sequentially.
  --validate_only       Write QC and PCA diagnostics without running GWAMA.
                        Default: false.
  --allow_missing_traits
                        Remove absent manifest traits with reasons. Default:
                        stop if absent.
  --failed_ldsc_action {error,drop_traits}
                        Invalid trait/pair estimates: error (default), or
                        audited deterministic trait removal; never impute.
  --h2_z_warn_threshold H2_Z_WARN_THRESHOLD
                        Warn for retained h2/SE below this value; never
                        removes traits. Default: 2; 0 disables.
  --rg_out_of_range_action {warn,error}
                        Finite off-diagonal abs(rg)>1: warn (default) or
                        error; never clamp.
  --pca_matrix {correlation,covariance}
                        correlation uses S_Stand (default); covariance uses
                        native S, on its original scales.
  --pc1_orientation {tutorial,as_computed}
                        tutorial (default): flip ALL PC1 loadings if median<0;
                        as_computed keeps eigenvector sign.
  --negative_eigen_action {warn,error}
                        Substantive negative PCA eigenvalues: warn (default)
                        or error; no matrix repair.
  --matrix_eigen_tolerance MATRIX_EIGEN_TOLERANCE
                        Relative negative-eigenvalue threshold. Default: 1e-8.

INPUT FILE CONTRACT
  --input: comma-separated CSV with unique, non-empty traitname header.
    Manifest row order defines matrix, loading and GWAMA input order.
    Package auto-preparation also requires vcf_files if the input folder is omitted.
  --ldsc_path: binary RData containing LDSCoutput, with S,V,I,S_Stand,V_Stand.
    This is NOT a delimited table. Generate it upstream with stand=TRUE.
  --gpca_input_folder: tab-separated TSV files; exact column order:
    SNPID,CHR,BP,EA,OA,EAF,N,Z,P (A1/A2/p aliases accepted for EA/OA/P).
    Split: {traitname}_chr{CHR}_GenomicPCA_inputs.tsv (chromosomes 1-22).
    Whole genome: {traitname}_GenomicPCA_inputs.tsv.
  --source_path: optional custom modified GWAMA R source; default is bundled v1.2.6.

AVAILABILITY
  genomicsem ldsc runs native munge/LDSC or accepts existing munged files.
  Both PCA matrix choices write all-PC variance and PC1 protein contributions.
  GWAMA uses PC1 only. Native covariance uses S on its supplied scales.
