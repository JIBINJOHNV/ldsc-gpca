usage: ldsc-gpca gpca --input MANIFEST.csv --ldsc_results LDSC.csv[.gz] --outdir DIRECTORY [options]

Build genomic-PC1 weights and run the modified Fuertjes GWAMA method
using a complete pairwise results table produced by Python ldsc.py.

options:
  -h, --help                    Show this help message and exit.

Required inputs:
  --input MANIFEST.csv          CSV trait manifest. Required column: 'traitname'. No other
                                manifest columns are required; extra columns are ignored. Trait
                                names must be unique/non-empty, and row order defines matrix and
                                GWAMA order. [Required; no default.]

  --ldsc_results LDSC.csv[.gz]  Complete pairwise Python LDSC table in CSV/TSV format; gzip is
                                accepted. Required columns are listed below. [Required; no
                                default.]

  --outdir DIRECTORY            Directory for QC audit files, matrices, weights, and GWAMA
                                results. [Required; no default.]

GWAMA inputs (not required with --validate_only or --pc1_only):
  --gpca_input_folder DIRECTORY
                                Directory containing the nine-column per-trait GWAMA input
                                files. Default: unset; package CLI prepares from VCF unless
                                --validate_only or --pc1_only. Required for GWAMA when calling R
                                directly.

  --source_path GWAMA_FUNCTION.R
                                Optional custom modified GWAMA R source. Default: bundled
                                N_weighted_GWAMA.function.1_2_6.R.

  --splitby_chr CHOICE          GWAMA input layout: 'split' uses chromosomes 1-22; 'nosplit'
                                uses one whole-genome file per trait. Default: split. [Choices:
                                split, nosplit.]

Trait and failed-result handling:
  --allow_missing_traits        Remove manifest traits absent from the LDSC table. Without this
                                flag, an absent selected trait stops the run. Extra LDSC traits
                                are ignored. [Default: off.]

  --failed_ldsc_action CHOICE   For missing/non-finite/invalid selected pairs: 'error' stops;
                                'drop_traits' removes traits until a complete valid subset
                                remains. No estimates are imputed; this does not enable
                                numerical CTI exclusions. Default: error. [Choices: error,
                                drop_traits.]

QC comparison thresholds:
  --duplicate_tolerance FLOAT   Maximum absolute difference between duplicate orientations for
                                rg, SE, p, and intercept estimates, including self-pair
                                heritability and SE. Default: 0.001.

  --duplicate_z_tolerance FLOAT
                                Maximum absolute duplicate-orientation z difference. Default:
                                0.01.

  --self_rg_tolerance FLOAT     Maximum |self rg - 1|. Default: 0.01 (self rg from 0.99 through
                                1.01). Self rg SE=0 is allowed only with Z=+Inf and P=0; other
                                checks still apply.

  --comparison_epsilon FLOAT    Floating-point allowance added to boundary comparisons. Default:
                                1e-12.

PCA settings:
  --heritability_scale CHOICE   Heritability columns used for self-pair QC and covariance PCA.
                                'auto' uses populated values for selected traits, ignoring empty
                                pairs. Correlation: per-trait scale; covariance: one complete
                                common scale. 'mixed' explicitly permits trait-specific
                                covariance scales, only when each trait has one populated scale.
                                Ambiguity stops; no conversion. Default: auto. [Choices: auto,
                                liability, observed, mixed.]

  --rg_normalization CHOICE     Correlation source: 'pair' keeps native Python rg; 'trait_wide'
                                uses the precomputed rg_trait_wide column (normalization_status
                                must be calculated). Original rg/SE/Z/P and CTI are preserved.
                                Default: pair. [Choices: pair, trait_wide.]

  --pca_matrix CHOICE           Matrix decomposed for PC1: 'correlation' uses S_Stand;
                                'covariance' derives genetic covariance from selected rg and
                                selected-scale self h2, following the tutorial alternative
                                procedure. CTI is unchanged. Default: correlation. [Choices:
                                correlation, covariance.]

  --pc1_orientation CHOICE      PC1 sign convention. 'tutorial' flips the entire loading vector
                                when its median is negative; 'as_computed' keeps R's eigenvector
                                sign. Association strength and p-values are unchanged. Default:
                                tutorial. [Choices: tutorial, as_computed.]

Diagnostic warning/error controls:
  --h2_z_warn_threshold FLOAT   Warn when retained self-pair h2/SE is below this value.
                                Diagnostic only; never removes traits. Use 0 to disable.
                                Default: 2.

  --z_consistency_tolerance FLOAT
                                Maximum relative difference between reported z and rg/SE after
                                duplicate collapse. Default: 0.01.

  --z_consistency_action CHOICE
                                Warn or stop when z is inconsistent with rg/SE. Default: warn.
                                [Choices: warn, error.]

  --rg_out_of_range_action CHOICE
                                Warn or stop for finite off-diagonal rg outside [-1,1]. Values
                                are never clamped. Default: warn. [Choices: warn, error.]

  --negative_eigen_action CHOICE
                                Warn or stop for substantive negative selected-PCA-matrix
                                eigenvalues anywhere, not just PC1. No trait removal or CTI
                                repair; invalid PC1 always stops. Default: warn. [Choices: warn,
                                error.]

  --matrix_eigen_tolerance FLOAT
                                Relative cutoff separating substantive negative eigenvalues from
                                floating-point noise. Default: 1e-8.

Execution and performance:
  --validate_only               Assess PC1 and CTI separately and write audits without GWAMA;
                                required-check failures return an error. [Default: off.]

  --n_cores INTEGER             Workers for chromosome-split GWAMA. 0 selects up to 22 based on
                                available physical cores. Default: 0. Failed jobs retry once in
                                fresh workers, one at a time; failure after 2 attempts stops
                                analysis.

  --ldsc_chunk_size INTEGER     Number of LDSC rows read per streaming chunk. Default: 250000.

  --color CHOICE                Help-message colour: auto for terminals, always to force it, or
                                never to disable it. NO_COLOR is respected in auto mode.
                                Default: auto. [Choices: auto, always, never.]

PC1 and CTI validation:
  --pc1_only                    Save PC1 and both validation reports without GWAMA. CTI failure
                                is nonblocking; invalid PC1 still stops. Default: off.

  --cti_action CHOICE           CTI failure policy: error stops combined validation/GWAMA;
                                explore_drop tries audited eigenvector-based trait exclusions
                                and rechecks BOTH matrices. No matrix repair. Default: error.
                                [Choices: error, explore_drop.]

  --max_cti_drop_fraction FLOAT
                                Maximum fraction of traits entering CTI assessment to exclude (0
                                <= value < 1). explore_drop requires an explicit positive limit.
                                Not a biological cutoff. Default: 0.

INPUT FILE FORMATS
  Manifest: comma-separated CSV with a header row.
  Python LDSC: CSV, tab-separated TSV or whitespace-delimited text;
    separator is detected from the header; gzip (.gz) is accepted.
  GWAMA inputs: tab-separated TSV, required columns (extra/reordered columns allowed):
    SNPID,CHR,BP,EA,OA,EAF,N,Z,P
    A1/A2/p aliases are accepted for EA/OA/P.
  Split files: {traitname}_chr{CHR}_GenomicPCA_inputs.tsv
  Whole-genome files: {traitname}_GenomicPCA_inputs.tsv
  --source_path: optional custom modified GWAMA R source; default is bundled v1.2.6.

GWAMA OUTPUT QC
  Zero available weight or invalid BETA/Z/P/SE/N fails before success/export.
  P=0 underflow is valid. Raw results and *.GWAMA_QC_* audits are retained.
  No undefined row is silently excluded or assigned a fabricated Z.

REQUIRED MANIFEST COLUMN
  traitname    Unique, non-empty trait identifier. Each row selects one
               trait, and row order defines all analysis matrices.
  Direct R needs no other manifest columns. The package CLI additionally
  requires vcf_files if --gpca_input_folder is omitted for preparation.

REQUIRED PYTHON LDSC COLUMNS
  Always required:
    p1, p2, rg, se, z, p, h2_int, h2_int_se, gcov_int, gcov_int_se
  Plus one complete heritability pair:
    h2_liab, h2_liab_se  OR  h2_obs, h2_obs_se
  Auto ignores empty pairs; ambiguous populated scales require a choice.
  Malformed numeric text is fatal under every policy; errors name field/row.
  Mixed-scale covariance requires --heritability_scale mixed.

MATRIX DEFINITIONS
  Correlation matrix: diagonal = 1; off-diagonal = selected rg normalization
  Covariance matrix:  diagonal = selected-scale self h2; off-diagonal =
                      selected rg * sqrt(h2_1 * h2_2)
  GWAMA CTI matrix:  diagonal = h2_int; off-diagonal = gcov_int

PC1 SIGN CONVENTION
  Default --pc1_orientation tutorial: multiply the entire PC1 loading
  vector by -1 when its median is negative. Use 'as_computed' only to
  retain R's arbitrary eigenvector direction for legacy comparison.

IMPORTANT DEFAULTS
  Extra LDSC traits are ignored. Missing or invalid selected values stop
  the run. No LDSC value is imputed or silently clamped. Use
  --failed_ldsc_action drop_traits only for missing/invalid estimates.
  CTI exclusions require --cti_action explore_drop and an explicit limit.

VALIDATION-ONLY EXAMPLE
  Rscript gpsca_gwama_python_ldsc.r \
    --input selected_traits.csv \
    --ldsc_results all_pairwise_ldsc.csv.gz \
    --outdir validation_results \
    --failed_ldsc_action drop_traits \
    --validate_only

Run with GWAMA by additionally providing --gpca_input_folder and
an optional --source_path override, and omit --validate_only.
